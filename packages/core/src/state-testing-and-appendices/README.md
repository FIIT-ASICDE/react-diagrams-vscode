# State diagram testing and appendices
This repository contains appendices, documentation, samples and experiment for the state diagrams thesis.

Contents:
* TechnicalDocumentation.docx - Contains the technical documentation for the architecture of the state diagram extension, providing high level overview and explaining the most important concepts and parts. Including some selected code examples.
* UserManual.docx - Contains the user manual for the state diagram extension, explaining how to use the extension and its features for the practical/functional
point of view for a potential user. Complement to TechnicalDocumentation.
* SanityCheck_DoLLMsUnderstandRepresentationOfOurDiagrams.docx - Full report and results documenting the tests conducted for **Do LLMs understand the representations of our diagrams and how deep is that understanding?** thesis question, including full sample date of the diagrams used during the tests as well as the full responses the models gave during the tests as well as rational behind the subtracted points.
* SanityCheck_DoLLMsUnderstandRepresentationOfOurDiagrams.xlsx - Evaluation digest from SanityCheck_DoLLMsUnderstandRepresentationOfOurDiagrams.docx containing the final score table with appropriate graph, that were used in the thesis.
* ./samples - Contains testing samples that were used during the extensions development for testing its functionality. ifElseChain.tsx and switchNLoops.tsx were also used in SanityCheck_DoLLMsUnderstandRepresentationOfOurDiagrams.docx test. Respective images used in this test are also included.
* ./experiments/refactoring - Contains the full sample dataset (under _Base folder) as well as refactored results used in **Will adding diagram context yield simpler component refactors, and will it even work?** thesis question.
Also contains the evaluator source code that was used to evaluate and subsequent report generation for the files refactored by the models for respective Code and CodeAndDiagram scenario.
Note that the source code of the evaluator needs to be put under packages/core/src of the main source code repository (https://github.com/FIIT-ASICDE/react-diagrams-vscode) which may contain copy of this repository.
State diagrams themselves were primarily developed on https://github.com/FIIT-ASICDE/react-diagrams-vscode/tree/feature/state-diagrams branch.

Available online link: https://github.com/FIIT-ASICDE/state-testing-and-appendices/
